# climate-nob

Small vanilla JS climate data visualization page — front-end learning exercise.

## The problem

You are practicing fetch/render loops and basic charting in the browser without reaching for a framework.

## What it does

Single-page app in `index.html`, `script.js`, and `style.css` displaying climate-related data interactively.

## Install

```bash
git clone https://github.com/irachrist1/climate-nob.git && cd climate-nob
open index.html
```

## How it works

- **Vanilla JS rendering.** DOM updates driven by fetched or embedded data — see the full pipeline in one file.
- **CSS presentation layer.** Visual hierarchy separated from data logic in `style.css`.
- **Learning sandbox.** Not a production climate product — exercise in data + UI wiring.
